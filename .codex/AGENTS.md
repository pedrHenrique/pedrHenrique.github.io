# Instruções do repositório

Sempre que alterar qualquer arquivo em `public/profile*.json`, execute `python scripts/convert_profiles_to_toon.py` para atualizar os arquivos TOON correspondentes antes de concluir a tarefa.

## TOON FILES

Os arquivos `**/*.toon` são apenas para leitura e nunca devem ser modificados diretamente. Eles existem no projeto apenas para reduzirmos o consumo de tokens.
